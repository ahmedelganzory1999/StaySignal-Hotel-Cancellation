StaySignal GitHub upload steps (Windows)

1. Unzip StaySignal_GitHub_Ready.zip.
2. Create a public GitHub repository named StaySignal-Hotel-Cancellation. Do not auto-add a README.
3. In GitHub, Add file > Upload files. Drag ALL items inside the unzipped folder, including the hidden .streamlit directory. Do not upload the ZIP as one file, and do not drag the parent folder.
4. Verify that app.py and requirements.txt are in the repository root, and that model/, data/, pages/, utils/ and .streamlit/ appear alongside them.
5. Commit changes to main.
6. Open https://share.streamlit.io, connect GitHub, and choose this repository. Select branch main and main file path app.py. Set Python 3.11 in Advanced settings if available. Deploy.
7. Open the public app and test each page and a prediction. Copy the public streamlit.app URL into the project README and final submission.
8. Ensure the video and official Epsilon AI GitHub repo reference are supplied as required by the PDF.
